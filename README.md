# Structural Design of a Five-Story Residential Building

## Overview
This repository presents the structural design and documentation of a five-story reinforced concrete residential building completed as an academic project at Chittagong Polytechnic Institute. The project covers the complete design process, including structural calculations, engineering drawings, and quantity estimation. It demonstrates the application of reinforced concrete design principles to a multi-story residential structure.

## Project Highlights
- Structural drawings
- Slab design
- Balcony slab design
- Beam design
- Column design
- Footing design
- Stair design
- Septic tank design
- Quantity estimation
- Cost estimation
